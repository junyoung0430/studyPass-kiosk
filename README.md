# StudyPass Kiosk 🪑

무인 스터디카페에서 손님이 직원 없이 **이용권 구매 → 좌석 선택 → 결제 → 입실 → 퇴실**까지 혼자 할 수 있는 키오스크 화면과,
매장 관리자가 좌석 현황과 매출을 확인하는 **관리자 화면**을 만든 프로젝트입니다.

> 개인 학습용 포트폴리오 프로젝트입니다. 모든 데이터는 가상이며 실제 결제는 이루어지지 않습니다.

## 만든 이유
스터디카페, 독서실 같은 무인 매장은 직원이 없어도 손님이 헤매지 않고 이용할 수 있어야 하고,
관리자는 매장에 가지 않아도 좌석과 매출 상황을 알 수 있어야 합니다.
이 두 가지를 웹 화면으로 직접 구현해 보며 비대면 서비스의 흐름을 이해하고 싶었습니다.

## 주요 기능

### 키오스크 화면
| 기능 | 설명 |
|---|---|
| 휴대폰 번호 입력 | 화면 숫자 키패드로 입력, 8자리를 모두 입력해야 다음 단계 가능 |
| 중복 입실 방지 | 이미 이용 중인 번호로는 다시 입실할 수 없음 |
| 이용권 선택 | 2시간 / 4시간 / 6시간 / 종일권, 지금 입실하면 몇 시까지 이용 가능한지 표시 |
| 좌석 선택 | 구역별 좌석 배치도, 사용 중인 좌석은 선택 불가 |
| 결제 (가상) | 신용카드 / 간편결제 선택 → 결제 중 화면 → 완료 |
| 출입 인증번호 | 입실 완료 시 4자리 출입 인증번호 발급 |
| 퇴실 | 번호 입력 → 이용 시간 확인 → 퇴실 처리 |
| 자동 처음 화면 | 60초 동안 입력이 없으면 처음 화면으로 (다음 손님이 앞사람 정보를 보지 못하게) |
| 개인정보 가림 | 휴대폰 번호 가운데 4자리를 `****`로 표시 |

### 관리자 화면
| 기능 | 설명 |
|---|---|
| 요약 | 사용 중 좌석, 좌석 이용률, 오늘 입실 수, 오늘 매출 |
| 실시간 좌석 현황 | 좌석별 남은 시간, 30분 이하 남은 좌석은 주황색 표시 |
| 이용 기록 | 입실 / 퇴실 / 자동퇴실 기록을 최신순으로 표시 |
| 자동 퇴실 | 이용 시간이 끝난 좌석은 자동으로 퇴실 처리 |

## 사용 기술
- HTML, CSS (Flexbox, Grid, 미디어쿼리)
- JavaScript (DOM 조작, 이벤트 처리, 배열 메서드, setTimeout / setInterval)

## 파일 구조
```
studypass-kiosk/
├── index.html   # 키오스크·관리자 화면 구조
├── style.css    # 디자인, 반응형
├── data.js      # 이용권, 좌석 구역, 가상 이용 데이터
└── script.js    # 화면 전환, 입실·퇴실, 결제, 관리자 화면
```

## 실행 방법
`index.html`을 브라우저로 열면 됩니다.
데모용 퇴실 번호: `010-1234-5678` (2번 좌석)

## 앞으로 개선하고 싶은 점
- 서버와 DB를 연결해 여러 키오스크와 관리자 앱이 같은 데이터를 보도록 만들기
- 출입 인증번호 대신 QR 코드로 출입하기
- 이용 시간 종료 10분 전 문자 알림 보내기
